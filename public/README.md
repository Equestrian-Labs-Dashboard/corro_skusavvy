# Atletix Horse Sales Report

Static GitHub Pages dashboard for Atletix Horse reporting.

## What this version includes

- Month and Quarter reporting.
- H1/H2 Review with manual Atletix Request rows.
- Inventory Overview.
- Inventory Rotation.
- Inventory Turnover.
- CSV export.

## Inventory metric formulas

Inventory Rotation = Units Sold / Average Inventory Units

Inventory Turnover = COGS / Average Inventory Value

Required fields used for turnover:

- Opening Inventory
- Ending Inventory
- Average Inventory Units
- Unit COGS / COX
- Total COGS / COX
- Average Inventory Value

## Data update

Shopify data is generated by GitHub Actions into `data/report.json`. The dashboard Refresh button reloads the latest published JSON.
